# Web Discover

A lightweight, single-file web application and directory browser built with Tailwind CSS and vanilla JavaScript. Designed as a clean client-side startpage and site discovery hub with integrated JSON list building tools.

## Key Features

* **Directory & Catalog**: Browse, search, and filter a curated list of websites across multiple categories.
* **Featured Showcase**: Auto-rotating hero banner highlighting top picks with smooth transitions.
* **Discover Portal**: Single-card evaluation view to quickly review sites with ignore, visit, and save actions.
* **Custom Site Management**: Add custom websites directly into local storage.
* **JSON List Builder**: Interactive builder tool to select items and export clean JSON objects.
* **Local Persistence**: Bookmarks and saved sites persist using browser `localStorage` with backup export capabilities.

## Tech Stack

* **Frontend**: HTML5, Tailwind CSS (via CDN)
* **Icons**: Lucide Icons
* **Logic**: Vanilla JavaScript (ES6+)

## Getting Started

1. Clone or download the repository.
2. Open `index.html` directly in any modern web browser or serve it via a local development server.

---
*No backend server or complex configuration required.*
